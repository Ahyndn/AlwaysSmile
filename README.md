# AlwaysSmile — Inventory and Merchandise Management System

**Project Status: Under Active Development**

AlwaysSmile is a Django-based inventory and merchandise management application incorporating inventory analytics, logistics monitoring, architectural floor planning, and merchandise planogram functionality.

This repository is currently undergoing active development. Some features are operational, while others are being implemented, optimized, or refined.

## Project Features

- Inventory Management
- Inventory Analytics
- Logistics Dashboard
- Merchandise Management
- Architectural Floor Planning
- Interactive Planogram Management
