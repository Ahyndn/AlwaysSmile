# AlwaysSmile — Business Operations SAAS Demo

**Project Status: Under Active Development**

AlwaysSmile is a Django-based business operations SAAS Demo incorporating inventory analytics, logistics monitoring, floor plan, merchandise planogram functionality amd price setting functionality. It can also be considered as a template for future usage. Heavily mentioned details regarding: scaling for research, AI backed support, academia and commerical usage demonstrate the potential of this application [[43](https://github.com/ishandutta2007/Awesome-Planogram-Management)]. Everything used to build is open sourced and will be open-source license for usage.

This repository is currently undergoing active development. Some features are operational, while others are being implemented, optimized, or refined.

## Project Features

- Inventory Management
- Inventory Analytics
- Logistics Dashboard
- Planogram
- Price Planner
