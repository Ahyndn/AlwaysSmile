Calculation Definitions

1. Estimated Units Sold

Estimated Units Sold = max(0, MOQ - Stock)

2. Estimated Sales Value

Estimated Sales Value = Estimated Units Sold × Product Price

3. Cumulative Percentage

Cumulative Percentage = (Cumulative Sales Value / Total Sales Value) × 100

4. ABC Classification

  • Class A: cumulative percentage up to 80%.
  • Class B: cumulative percentage above 80% and up to 95%.
  • Class C: cumulative percentage above 95%.

Important: These figures are estimated using the existing inventory calculation methodology. They do not represent actual historical sales transactions.
